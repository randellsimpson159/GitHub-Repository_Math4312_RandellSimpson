Function Explorer is an interactive Shiny application that asks users to enter a simple function, such as x^2, sin(x), 1/x, or x^3 - 3x. The application validates the input, classifies the function type, computes a numerical derivative, identifies approximate critical points, and estimates global extrema over a user-selected interval.

The project began as a basic Shiny app that displayed a user’s response to the prompt, “Give an example of a function.” I expanded it into a more complete mathematical modeling tool by adding expression validation, rule-based AI classification, visualizations, and calculus-based analysis.

This project is an interactive R Shiny application that asks users, “Give an example of a function.” The app includes a text input box where users can type a response, such as x^2 or sin(x). When the user clicks the Add Function button, the app displays the exact text they entered in a list below the prompt.

This project demonstrates the basic structure of a Shiny app, including creating a user interface.
